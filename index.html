部署与视频配置指南（主试参考）

本页面为纯静态单页应用（index.html），无需后端数据库即可直接托管并分发链接给被试：

// 推荐目录结构：
├── index.html # 本问卷网页入口
└── videos/ # 存放 4 个冲突解脱实验视频
├── 1 (或 1.mp4)
├── 2 (或 2.mp4)
├── 3 (或 3.mp4)
└── 4 (或 4.mp4)
  • 文件名规则：页面会自动尝试 ./videos/1.mp4、./videos/1.mov、./videos/1（无扩展名）等候选路径，命中即播放，无需手动配置扩展名。
  • 如何修改文件名：用文本编辑器打开 index.html，在顶部的 VIDEO_CONFIG 数组中修改对应的 file / src 即可。
  • 视频数量变化：若视频总数不再是 4 个，请同时修改顶部的 VIDEO_COUNT 常量与 VIDEO_CONFIG 数组。
  • 托管平台建议：上传至 GitHub Pages、Vercel、Cloudflare Pages 或实验室局域网静态服务器后，将生成的网址直接发送给被试即可。
  • 数据回收：被试提交后会自动下载包含姓名、年龄、经验年限、视频观看时长及全部量表/文本答案的 CSV 与 JSON 文件，直接发回给您即可汇总分析。
